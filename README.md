## 🎬 什么是栖象工作室？

栖象工作室是一款 AI 驱动的**桌面端漫剧创作工具**，覆盖从小说创作到视频成片的完整工作流。无论你是网文作者、漫画创作者、视频制作人，还是 AIGC 爱好者，都能在这里找到高效的创作方式。

---

## ✨ 核心功能

### 📖 小说创作引擎

AI 辅助生成世界观设定、角色档案、故事大纲与章节正文。独创**五大上下文系统**，保证长篇叙事的人物、情节、设定始终一致，告别"前文不搭后文"的尴尬。

- 自动生成角色档案、世界观设定
- 智能大纲编排，支持多线叙事
- 章节正文 AI 续写，风格统一
- 完成后一键导入为漫剧项目

### 🎬 分镜自动生成

将剧本交给 AI，自动解析出完整的分镜脚本——包含景别、构图、情绪描述与图像提示词，一键生成每帧画面。

- 剧本智能解析，自动拆分镜头
- 景别、构图、运镜自动推荐
- 生成图像提示词，直连 AI 绘画
- 支持手动调整与重新生成

### 📦 资产统一管理

角色、场景、道具一站式管理。AI 生成参考图与提示词，所有素材支持跨项目复用，再也不用到处找素材。

- 角色库：统一管理与复用角色形象
- 场景库：保存场景设定与参考图
- 道具库：道具素材分类归档
- AI 自动生成参考图与提示词

### 🎥 AI 视频生成

接入**豆包、可灵、MiniMax、Sora** 等 8+ 主流视频生成模型，分镜自动规划视频段落，让静态画面动起来。

- 8+ 视频模型自由切换
- 分镜自动转视频片段
- 支持图生视频、文生视频
- 视频参数精细调控

### 🤖 Agent 对话创作

通过自然语言对话，让 AI 帮你完成小说创建、角色设定、分镜规划等任务。内置 **45+ 专业工具**自动调用，你说需求，它来执行。

- 自然语言驱动创作流程
- 45+ 工具自动调用
- 支持多轮对话与上下文理解
- 覆盖创作全链路任务

### 🖼️ 节点式创作画布

**24 种节点**自由组合，将图片生成、视频编辑、文本推理、3D 导演台串联成可视化流水线。拖拽连接，所见即所得。

- 24 种功能节点
- 可视化拖拽连线
- 实时预览节点输出
- 支持自定义工作流模板

### 🎬 3D 导演台

内置 **Three.js** 场景编辑器，自由摆放模型与道具，AI 生成专业灯光，一键截取镜头画面。无需 3D 基础也能导演大片。

- 3D 场景自由搭建
- AI 自动布光
- 多角度镜头截取
- 导出高质量画面

### ✂️ 内置视频编辑器

集成 **OpenCut** 视频编辑引擎，时间线编辑、WebGL 渲染、特效添加、语音转文字，从剪辑到导出成片一步到位。

- 多轨道时间线编辑
- WebGL 硬件加速渲染
- 转场、特效、字幕
- 语音自动转文字
- 一键导出成片

## 🚀 快速开始

### 下载安装

栖象工作室支持 **macOS、Windows** 三大平台：

1. 访问 [https://www.qixiangai.chat/](https://www.qixiangai.chat/) 下载对应版本
2. 安装并启动应用
3. 前往 **设置 → AI 模型** 配置至少一个 Provider 的 API Key
4. 开始创作！

> 💡 最低配置只需一个文本模型（LLM）和一个图像模型即可开始使用，视频和音频模型可在需要时再配置。

### 配置 AI 模型

详细配置方式请参考 [AI 模型配置文档](https://www.qixiangai.chat/guide/ai-models.html)。
