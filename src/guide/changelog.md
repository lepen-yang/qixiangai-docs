# 更新日志

## v1.0.20 <Badge type="tip" text="最新" />

**发布日期：** 2026-08-02

### 核心功能

- 小说创作引擎：AI 一键生成设定、角色、大纲与章节正文，内置五大上下文系统（本体约束、事件溯源、角色状态、对话图鉴、远距离记忆）
- 漫剧项目管理：角色、场景、道具、剧集全流程管理，支持从小说导入、从剧本提取资产
- 分镜自动生成：剧本 → AI 解析分镜脚本，包含景别、构图、镜头描述、情绪标签与图像提示词
- AI 图像生成：12 家图像 Provider，支持角色/场景/道具参考图与分镜图片生成
- AI 视频生成：8 家视频 Provider，分镜自动规划视频段落，内置崩溃恢复
- AI 音频生成：3 家音频 Provider，角色独立配音配置，TTS + 背景音乐
- Agent 对话助手：45+ 内置工具，自然语言完成创作任务，支持联网搜索
- 节点式创作画布：24 种节点类型，分镜序列生成、3D 灯光生成、图片处理工具
- 3D 导演台：Three.js 场景编辑器，角色模型摆放、灯光调整、镜头截取
- 内置视频编辑器：OpenCut 集成，时间线编辑、WebGL 渲染、特效、语音转文字
- FFmpeg 处理：内置二进制，裁剪、拼接、音轨合并、格式转换
- 语音识别：本地 Whisper 推理，自动生成字幕
- 提示词管理：30+ 内置系统 Prompt，支持自定义覆盖
- 自动更新：新版本静默下载，下次启动自动应用

### 支持平台

- macOS 12+（Apple Silicon）
- Windows 10 / 11（64-bit）
- Linux（AppImage / deb）

### AI 模型支持

- 文本：Doubao、MiniMax、Qwen、SiliconFlow、147api、OpenAI
- 图像：Doubao Seedream、MiniMax、Wanx、Kling、SiliconFlow、147api、PPIO、Ideogram、Fal、GRSai、KIE、Dreamina
- 视频：Doubao、MiniMax、Wanx、Kling、SiliconFlow、147api、Sora、Dreamina
- 音频：Doubao Seed-TTS、MiniMax、ElevenLabs
