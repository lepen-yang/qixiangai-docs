# 常见问题

## 安装与启动

**macOS 提示"无法验证开发者"怎么办？**

前往 **系统设置 → 隐私与安全性**，在页面底部找到关于 栖象工作室 的提示，点击「仍要打开」即可。首次打开后后续不再提示。

**Windows 安装时被安全软件拦截怎么办？**

安装包未经 EV 代码签名，部分安全软件会误报。可临时关闭实时防护完成安装，安装后重新开启。应用本身不包含任何恶意代码。

**Linux AppImage 无法运行怎么办？**

确保已赋予执行权限：`chmod +x qixiang-studio-*.AppImage`。如果仍无法运行，检查系统是否安装了 FUSE：`sudo apt install libfuse2`。

**启动后白屏怎么办？**

通常是显卡驱动问题。请确保显卡驱动支持 OpenGL 3.3 以上。macOS 用户确保系统版本 12 以上。如问题持续，尝试在设置中关闭硬件加速后重启。

## AI 功能

**AI 生成图像很慢，正常吗？**

生成速度取决于所选模型和网络状况。云端模型通常 10–30 秒出图，视频生成可能需要 1–5 分钟。部分模型支持快速模式（turbo），可显著缩短生成时间。

**API Key 填写后提示无效？**

请检查 Key 是否有多余空格或换行符。确认账户余额充足。部分模型需要特定地区的网络环境。如果使用第三方中转平台（SiliconFlow、147api、PPIO），请确认中转平台支持你选择的模型。

**即梦 CLI 无法安装怎么办？**

即梦 CLI 安装需要网络连接。如果安装失败，检查网络代理设置。也可以手动安装后，在设置中点击「检查状态」验证是否已正确识别。

**即梦 CLI 登录后显示积分为 0？**

确认你的即梦账户是否有可用积分。部分模型需要付费积分。如网络波动导致积分接口不可达，系统会显示琥珀色提示而非红色「未登录」，此时可正常使用。

**AI 生成的分镜图片风格不一致怎么办？**

使用图生图模式：先为角色和场景生成参考图，然后在分镜图片生成时勾选参考图作为输入。AI 会根据参考图保持风格一致。也可以在画布中使用"连续分镜"工具生成风格一致的多帧画面。

**视频生成失败后怎么恢复？**

栖象工作室 内置视频生成恢复机制。如果应用意外关闭，下次启动时会自动扫描中断的任务并恢复处理。你也可以在剧集页面的「视频段落」标签中手动重新提交失败的任务。

## 小说创作

**AI 生成的章节内容与前文矛盾怎么办？**

检查五大上下文系统是否已开启（在小说页面的「上下文」弹窗中管理）。特别是「事件溯源」和「角色动态状态」这两项，它们是保证长篇一致性的关键。也可以手动添加本体规则（hard 级别）来约束 AI 生成方向。

**可以从外部导入小说文本吗？**

可以。在小说页面创建新小说后，手动粘贴或导入外部文本到章节中。AI 在后续生成时会参考已有内容。

## 更新

**如何手动检查更新？**

前往 **设置 → 关于与更新**，点击「检查更新」按钮。

**更新下载后需要重启吗？**

是的，更新包在后台下载完成后，下次启动应用时会自动安装新版本。

## 其他

**数据存储在哪里？**

应用数据存储在项目的工作目录（可在项目设置中查看）。数据库文件位于应用数据目录下。资产文件（图片、视频、音频）存储在项目工作目录的对应子文件夹中。

**遇到 Bug 如何反馈？**

请前往 [GitHub Issues](https://github.com/lepen-yang/qixiangai-docs/issues) 提交问题，附上操作步骤和截图，我们会尽快处理。

**支持哪些导出格式？**

视频编辑器支持导出 MP4 等常见视频格式。图片处理支持 PNG、JPEG、WebP 等格式。FFmpeg 服务支持视频格式转换与压缩。
