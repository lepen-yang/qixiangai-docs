# Agent 助手

栖象工作室 内置 AI 对话助手（Studio Agent），通过自然语言完成创作任务，无需手动操作每个功能。

## 对话模式

Studio Agent 基于 LangChain/LangGraph 构建，支持多轮对话与工具调用。你在输入框中描述需求，AI 会理解意图、自动选择并调用合适的工具，逐步完成任务。

整个对话过程支持流式输出，你可以实时看到 AI 的思考和回复。当 AI 调用工具时，界面会显示工具调用状态（思考中 → 工具调用中 → 回复中）和工具执行结果。

## 内置工具

Studio Agent 拥有 45+ 个内置工具，覆盖四大模块：

**小说工具（13 个）** — 创建/查询/更新/删除小说、角色和章节。例如"帮我新建一个赛博朋克题材的小说"会自动调用小说创建工具。

**项目工具（15 个）** — 创建/查询/更新/删除漫剧项目、角色、场景和道具。例如"在我的赛博朋克项目里加一个反派角色"会自动调用角色创建工具。

**剧集工具（17 个）** — 创建/查询/更新/删除剧集、分镜和视频段落。例如"把第一章剧本生成分镜"会自动读取剧本并调用 AI 分镜生成。

**媒体工具** — 图像生成（支持图生图）。例如"给这个角色生成一张参考图"会自动调用 AI 图像生成。

## 联网搜索

Agent 支持联网搜索功能。当你的问题需要外部信息时（如"最近流行的赛博朋克元素有哪些"），AI 会自动触发搜索，并在回复中引用来源链接。

## 媒体附件

你可以在对话中附带图片、视频或音频作为上下文。例如附带一张角色参考图，然后说"根据这张图帮我生成一个新角色"。

## Slash 快捷命令

输入框支持 `/` 触发快捷命令，快速插入常用创作指令：

- `/新建小说项目` — 创建一个全新的小说项目
- `/新建漫剧项目` — 创建一个全新的漫剧项目
- `/创建角色` — 生成一个详细的角色设定
- `/创建场景` — 生成场景描述
- `/生成世界观` — 为小说生成世界观设定
- `/规划故事大纲` — 根据核心概念生成故事大纲
- `/撰写章节正文` — 根据大纲撰写章节内容
- `/编写剧本` — 为漫剧编写分场景剧本
- `/规划分镜` — 将剧本转化为分镜脚本
- `/生成绘图提示词` — 为场景或角色生成 AI 绘图提示词

## 会话管理

每次对话会保存为会话记录，支持多会话切换。左侧会话列表可创建新会话、重命名和删除。会话标题会在首条消息后由 AI 自动生成。

## 使用示例

**创建项目** — "帮我新建一个漫剧项目，题材是末日废土，风格偏暗黑系"

**生成角色** — "在我的末日废土项目里加一个女主角，名字叫艾拉，性格坚强但有创伤"

**生成分镜** — "把第一集剧本生成分镜，注意要有紧张的追逐场景"

**生成图片** — "给艾拉生成一张参考图，风格是动漫写实"

**编写剧本** — "帮我编写第三集剧本，这集的主题是主角发现了一个地下避难所"

**优化文本** — "请帮我优化以下文本：……"
