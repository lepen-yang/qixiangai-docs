# 内置视频编辑器

栖象工作室 内置 OpenCut 视频编辑器，支持从时间线剪辑到特效合成的全流程，无需切换到外部软件。编辑器采用 WebGL 画布渲染，在 `/video-editor` 路由下以项目管理 + 编辑器两页式布局访问。

## 打开方式

视频编辑器有以下几种入口：

- **侧边栏导航** — 点击主界面左侧「视频编辑器」入口
- **画布节点** — 在创作画布中拖入「视频编辑」节点，将上游素材接入编辑器
- **分镜导出** — 分镜生成图片后，一键导入视频编辑器进行时间线编排

**路由结构：** `/video-editor/projects`（项目列表）→ `/video-editor/editor/:project_id`（编辑器）

## 编辑器界面

编辑器界面采用经典的三面板布局：

```
┌─────────────┬─────────────────┬──────────────┐
│  素材面板   │   预览画布      │   属性面板   │
│  (Assets)   │  (WebGL Preview)│ (Properties) │
├─────────────┴─────────────────┴──────────────┤
│              时间线 (Timeline)                │
└───────────────────────────────────────────────┘
```

![视频编辑器](https://liangx-gallery.oss-cn-beijing.aliyuncs.com/20260808231136361.png)

- **素材面板** — 导入媒体文件（视频、图片、音频）、管理素材库、拖拽素材到时间线
- **预览画布** — 基于 WebGL 的实时渲染画布，支持全分辨率预览与缩放
- **属性面板** — 选中时间线元素后，调整位置、缩放、透明度、旋转、混合模式等参数
- **时间线** — 多层轨道编辑，支持视频、音频、文字、特效、贴纸等轨道

## 时间线编辑

时间线支持多轨道并行编辑：

| 轨道类型 | 支持内容 | 操作 |
|---------|---------|------|
| **视频轨道** | 视频片段、图片序列 | 裁剪、拆分、拖拽调整顺序、速度变换 |
| **音频轨道** | 音频片段、背景音乐、配音 | 音量调节、淡入淡出、音频分离 |
| **文字轨道** | 标题、字幕、动态文字 | 字体、颜色、动画、描边、阴影 |
| **特效轨道** | 滤镜、转场、动态效果 | 叠加模式、强度调节、关键帧动画 |
| **贴纸轨道** | 贴图、形状、表情 | 缩放、旋转、透明度关键帧 |

时间线支持**关键帧动画** — 对任意属性（位置、缩放、旋转、透明度）设置关键帧，编辑器自动插值生成平滑过渡。

## 特效与合成

内置丰富的特效系统：

- **滤镜** — 色彩校正、LUT、模糊、锐化、噪点、风格化滤镜
- **蒙版** — 矩形蒙版、圆形蒙版、自由路径蒙版、反向蒙版
- **转场** — 淡入淡出、滑动、缩放、旋转、翻页等过渡效果
- **渐变** — 线性渐变、径向渐变、色彩映射
- **参考线** — 安全框、三分线、中心线、自定义参考线
- **音效** — 环境音效、音效库搜索、音量包络编辑

## 语音转文字（Whisper）

编辑器内置本地 Whisper 语音转文字推理能力：

- 在时间线导入音频/视频后，右键选择「转录」
- 自动识别语音内容并生成字幕轨道
- 支持中文、英文、日文等多语言识别
- 字幕可编辑、拆分、调整时间码
- 无需联网，完全本地推理，保护隐私

::: tip 💡 提示
首次使用转录功能时，会自动下载 Whisper 模型到本地。模型下载完成后，后续转录无需再次等待。
:::

## 导出与分享

编辑器支持多种格式导出：

| 格式 | 用途 | 说明 |
|------|------|------|
| **MP4** | 通用视频 | H.264 编码，兼容所有平台 |
| **WebM** | 网页分享 | 适合嵌入网页或在线预览 |
| **GIF** | 社交分享 | 短片段动态图导出 |
| **PNG 序列** | 后期处理 | 逐帧导出为图片序列 |

导出时可设置分辨率、帧率、码率、色彩空间等参数。大文件导出支持后台处理，不阻塞编辑器操作。

## 与画布联动

视频编辑器作为画布节点使用时，支持以下工作流：

```
[分镜图片] → [VideoGen 节点] → [VideoAsset 节点] → [VideoEdit 节点] → [导出成片]
                                      ↓
                              [AudioGen / TtsGen] → [背景音乐/配音]
```

你可以在画布中先批量生成视频片段，再统一接入视频编辑器节点进行剪辑合成，最后导出最终成片，全流程在一个应用内完成。

## 快捷键

| 快捷键 | 操作 |
|--------|------|
| `Space` | 播放 / 暂停 |
| `←` / `→` | 逐帧后退 / 前进 |
| `Shift + ←` / `Shift + →` | 快速后退 / 前进（每秒） |
| `I` | 设置入点（裁剪起点） |
| `O` | 设置出点（裁剪终点） |
| `C` | 激活刀片工具（拆分片段） |
| `V` | 激活选择工具 |
| `Delete` | 删除选中片段 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` | 重做 |
| `Ctrl + S` | 保存项目 |
| `Ctrl + E` | 导出视频 |
| `+` / `-` | 缩放时间线 |
| `F` | 时间线适配选区 |

## 项目与数据

视频编辑器使用独立的项目管理系统：

- 每个项目包含时间线、素材库、导出历史
- 项目数据自动保存到本地数据库，崩溃后可恢复
- 支持媒体文件自动同步（添加/删除/修改自动检测）
- 编辑器内部有数据迁移机制，版本升级时自动转换旧项目格式
