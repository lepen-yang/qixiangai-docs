# 系统要求

## 操作系统

| 平台 | 最低版本 | 推荐版本 |
|------|---------|---------|
| macOS | 12 Monterey | 14 Sonoma 及以上 |
| Windows | Windows 10 (64-bit) | Windows 11 |
| Linux | Ubuntu 20.04 / Debian 11 | Ubuntu 22.04 及以上 |

## 硬件配置

| 配置项 | 最低要求 | 推荐配置 |
|--------|---------|---------|
| CPU | 4 核 | 8 核及以上 |
| 内存 | 8 GB | 16 GB 及以上 |
| 存储 | 2 GB 可用空间 | SSD 10 GB 及以上 |
| 显卡 | 支持 Metal / DirectX 11 / OpenGL 3.3 | 独立显卡 |

::: tip 🎬 3D 导演台
3D 导演台使用 WebGL 渲染，需要支持 OpenGL 3.3 以上的显卡。大多数 2020 年后的设备均可流畅运行。
:::

## 网络

AI 生成功能需要联网调用云端模型 API。离线模式下可正常使用视频编辑、图片处理等本地功能。

语音转文字功能使用本地 Whisper 模型推理，首次使用需联网下载模型（约 100–500 MB），之后可离线运行。
